# SBOM schema fixture

`spdx-2.3.schema.json` contains the official schema authored by the SPDX
project contributors, copied from
[spdx/spdx-spec revision aadf3b0b8dbbabdb4d880b0fc714255fea436ff7 (v2.3)](https://github.com/spdx/spdx-spec/blob/aadf3b0b8dbbabdb4d880b0fc714255fea436ff7/schemas/spdx-schema.json).
The upstream repository licenses this material under Creative Commons Attribution
3.0 Unported; its original license text is preserved in [SPDX-LICENSE](SPDX-LICENSE).
The fixture retains that upstream license. JSON whitespace is formatted to this
repository's style; schema content is unchanged. It supports offline validation,
independently of Station's Apache license.

CycloneDX 1.6 validation uses the schema bundled with the pinned CycloneDX library.
