# Security Policy

## Supported Versions

Until Station reaches 1.0, security fixes are made against the latest release
line. Please reproduce against the newest available release when practical.

## Reporting a Vulnerability

Do not open public GitHub issues for suspected security vulnerabilities.

Report security issues through GitHub Security Advisories for this repository. If
that is not available, email `hello@kontourai.io` and include:

- a clear description of the issue
- affected versions or branches
- reproduction steps or a proof of concept
- impact assessment
- any suggested remediation

## Scope

Security reports are especially valuable for:

- authentication or authorization bypasses
- remote code execution or command injection
- sandbox, tool approval, or plugin permission escapes
- dependency or supply-chain risks
- secrets exposure
- unsafe file-system or network access

## Disclosure Expectations

- give maintainers reasonable time to investigate and patch the issue
- avoid public disclosure until a fix or mitigation is available
- keep proof-of-concept details private during remediation
