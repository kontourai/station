What Station does.

Bring the coding agents you already use

Run a Station agent on a local or hosted model, or connect supported agent CLIs and compatible custom engines. Each engine keeps its own tool loop. Station supplies Project context and records its activity.

Pick up where you left off

The plan, conversations, files, artifacts, and results stay linked to the Task. Reopen it to review the record, then check that its workspace is still available.

Understand Projects, Tasks, and Sessions

Review the changes and check results

Configured workflows can attach gate results, missing evidence, exceptions, and receipts to a Task. Completing a Task doesn’t mean a review or gate passed.

Run it on your own machine

Station stores its data on the computer that runs it. Connected model services, engines, devices, and integrations can send and receive data outside it. Desktop builds also check for updates.

From your first idea to what you ship.

Plan, build, and ship with your coding agents. Start on your own, then bring in teammates who can make decisions with you and take the work forward themselves. See progress as it happens, share what you learn, and build on work already done.

Team collaboration is in development. The current sharing limits are described below.

Today, you can invite people to a Project and give them a role. After signing in and getting their browser approved, they can read the Tasks you publish for them. Editing Tasks and running agents from that entry aren’t available yet. Review and member-presence UI include Feature Previews. Pairing connects your own devices; it isn’t team access.

What people use it for.

Ship a change with its checks attached

Open the repository as a Project, create a Task, pick an agent, and keep the commands that ran, their results, and the review receipts with the change.

Keep a long piece of work alive

A Task spans as many Sessions as it needs. Follow it from a paired device and come back to the same context, files, and evidence.

Use agents without a cloud account

A configured local model can provide inference without a cloud account. Tools, engines, and other enabled integrations retain their own network behavior.

Coordinate several agents

Delegate bounded work from one agent to another, or run it on a remote computer over SSH with that machine's own agents, credentials, and workspace.

Run it on a server you control

Build the container image from the checkout, run it behind your own authenticated ingress, and pair devices with scoped, revocable access. A published image is not yet available for anonymous pulls.

Run from source

macOS and Linux. Needs Node.js 24, npm 10 or newer, and git. Clone the repository, install dependencies with the managed lifecycle command, and start the app from the checkout.

Contributing guide

Published packages: @kontourai/station-sdk (plugin SDK), @kontourai/station-cli (client), @kontourai/station-contracts and @kontourai/station-shared (server, connection, and orchestration contracts plus shared helpers).
