Get started Product tour

Three things you do in Station.

  1. 1 Talk with your team
  2. 2 Bring your agents in
  3. 3 Get the project done

1 · Talk with your team

Every Project has its own channels.

A Project’s Room starts with #general. Add channels for design, a launch, or anything else, then rename or archive them as the work moves. Each channel keeps its own history and shared note.

  • Messages group by person and by day, and a reply opens a thread.
  • The sidebar lists each Project’s channels and Tasks, with unread counts.
  • On a phone, a channel opens full screen with the composer at the bottom.

Inviting other people uses Project sharing, which is still in development. Today, an invited person’s browser opens shared Projects read-only. Read the setup and current limits.

2 · Bring your agents in

Agents answer where everyone can read.

Choose Bring an Agent in a channel to ask one of your agents a question. Its answer comes back to that channel, marked as an agent, so the whole team reads it and replies in the same thread.

  • Recap Project prepares a request for an agent to summarize the Project, its Tasks and the discussion.
  • Run a Station agent on a local or hosted model, or connect supported agent CLIs and compatible custom engines.
  • Agent requests run on your Station, with the agents and connections you set up there.
Understand agents and connections

3 · Get the project done

Turn the conversation into a Task.

A Task keeps its plan, the agent work chats, and the recorded results together. Reopen it later, or from another device, and the record is still there.

  • Start a Task from a chat with New Task from this, or from a GitHub issue on the Project’s Tasks board.
  • Configured workflows can attach gate results, missing evidence and receipts. Completing a Task doesn’t mean a review or gate passed.
  • Pair a phone, tablet or laptop with scoped, revocable access, or send work to another computer you own over SSH.
