# Station UI style audit

Source snapshot `7fde8d816baed39c182fa185b99d1fe974dcdb1e`, with the installed `@kontourai/ui` 1.20.1. This audit covers presentation in the web shell, SDK, Connect, Basis pane and Board pane. The follow-up work belongs with the [UI polish epic](https://github.com/kontourai/station/issues/1225) and the [whole-app journey campaign](whole-app-ux-campaign.md).

## What to change first

1. **Give shared rows a predictable type hierarchy.** Settings already composes `PageRow` and `PageSection`, then reaches inside both components to reset type, padding and borders. In an isolated Chromium fixture loading the real stylesheets, a default row description measured 12px in both density modes. The same description inside Settings measured 13px in Comfortable and 12.5px in Compact. Start with the description role across Settings and Project settings. Give its type and line height one owner. Keep the screen-specific section header placement and mobile control layout where the two workflows need them. Compare ordinary and long descriptions in both densities before deleting the overlapping selectors. [Page layout](../../src-ui/src/views/page-layout.css) · [Settings overrides](../../src-ui/src/views/SettingsView.css) · [Settings row adapter](../../src-ui/src/views/settings/SettingsPageRow.tsx)
2. **Migrate spacing by computed value and intent.** Device setup asks for `var(--space-2, 8px)` between step labels and `var(--space-3, 12px)` between groups. Chromium measured 4px and 6px with Station’s tokens loaded. Switching those references to kit tokens with the same suffix would double both gaps. Inspect setup and the tools drawer together. Choose the desired spacing for related labels and separate groups, check the result in the narrow pane, and remove the misleading fallback. The kit already ships 4, 8, 12, 16, 24 and 32px. [Wizard](../../src-ui/src/workspace-panes/device/DeviceSetupWizard.css) · [Tools drawer](../../src-ui/src/workspace-panes/device/DeviceToolsDrawer.css) · [Station aliases](../../src-ui/src/tokens.css)
3. **Consolidate an actual pair of duplicates.** Connect’s discovery panel declared a secondary button style identical to the one device pairing already imports. The audit change routes discovery to that same package-local owner. Discovery’s primary button uses 8px × 14px padding and weight 600, while pairing uses 10px × 20px and weight 500. Decide whether those contexts need different emphasis before consolidating the primary action. Exercise discovery, manual pairing, disabled and pending actions, keyboard focus, and a standalone Connect consumer when changing the geometry. In the shell, desktop and server updates already demonstrate how to share status and action presentation while each caller supplies its own state. [Discovery](../../packages/connect/src/react/ConnectionManagerDiscoverPanel.tsx) · [Shared pairing styles](../../packages/connect/src/react/connection-manager-modal/styles.ts) · [Desktop updates](../../src-ui/src/views/settings/DesktopUpdateCheck.tsx) · [Server updates](../../src-ui/src/views/settings/CoreUpdateCheck.tsx)
4. **Keep global CSS small in responsibility.** Put shared tokens, theme/density overrides, focus behavior and opt-in composition recipes at the global entry. Keep the page gutter on the frame, row padding on the row and control padding on the control. Move feature selectors out of the global sheet as their owners are touched, checking lazy and standalone entry points. Its import comment still directs shell code to legacy tokens, in conflict with the UI agent instructions and current callers. Correct that comment when next updating the sheet. The existing sheet is 9,548 lines in the source snapshot and also contains feature-specific rules. A new universal reset would affect all of them. [Global entry](../../src-ui/src/index.css) · [Page frame](../../src-ui/src/components/page-frame/PageFrame.tsx) · [Layout recipes](../../src-ui/src/styles/layout-recipes.css)

The counts use the repo’s [CSS declaration reader](../../scripts/ui-css-slop.mjs). For each tracked stylesheet under `src-ui/{src,public}` and the four packages’ `src` directories, count a declaration once if its value contains a whitespace-delimited numeric `px`, `em` or `rem` length. The three families are `font-size`, `padding` including longhands, and `gap` including row/column gaps. Tests, fixtures and mocks are excluded. Expressions, custom properties and utility classes are outside the count. The largest concentrations are the global entry (335 declarations), Monitoring widgets (127), Plugin management (104) and Automations (84). These counts locate review work. A one-pixel optical adjustment and an ordinary content gutter deserve different treatment.

A TypeScript syntax pass over 1,042 TSX files in the same source roots found 526 JSX `style` attributes. Of those, 159 contain an object literal with a direct string or numeric literal for font size, padding or gap, including resets. Referenced style objects and dynamic values need separate inspection. Measured pane dimensions, drag coordinates, safe areas and 44px target floors have independent behavioral reasons to exist.

The [November 17 nightly gallery](https://github.com/kontourai/station/actions/runs/44131811484) captured 301 of 301 expected images at `23d7d9898660ec87182beb7aafbd00888524509e`. All image hashes matched the capture manifest. Contact sheets covered every capture. Original-size inspection included mobile Settings, Project settings, Connections and the usage-sharing dialog.

At 390px, Settings places “Your account” above the panel and indents its rows inside. Project settings puts “Overview and notifications” inside the card, with another inset before the first field. On mobile Connections, the search field is inset while the empty-state border reaches the viewport edge. These are useful direct comparisons for deciding who owns a page gutter, a section inset and a row inset. Preserve an intentional full-width rail or touch surface when choosing the shared default.

The hosted DOM audit recorded 232 finding occurrences on 71 captures, including 132 hit-target, 98 axe and two overflow entries. Both overflow entries identify the same Settings metadata selector at 320px. Repeated states can report the same underlying condition. Verify the actual clickable label or obstructed text on the affected screen before changing its geometry. Gallery capture and thumbnail inspection establish neither complete interaction coverage nor physical-device behavior. The source snapshot is newer than the gallery.

## Prevent recurrence

Use the [UI agent instructions](../../src-ui/AGENTS.md) at authoring time. Find one shipped caller with the same job, use its component and its owning stylesheet, then inspect the declarations the change makes redundant. Before changing a shared role, render the affected consumers at 390 and 1440px in light and dark. For type changes, compare Comfortable and Compact. For spacing changes, include a narrow pane inside a wide window and a long label. Verify keyboard focus, wrapping and touch area on the real controls.

For enforcement, extend the existing style checks in two stages. Start with an advisory on newly added literal font sizes, padding and gaps, including static JSX. Report the property, the owning component or published token to inspect, and the changed line. Exercise it against a real duplicate, a density-sensitive label, a responsive touch floor and dynamic geometry. Promote only findings that reliably distinguish the regression. The [component check](../../scripts/component-style-hygiene.mjs) already counts legacy references and selected bespoke controls. The [CSS check](../../scripts/ui-css-slop.mjs) handles colors and decoration in the shell. Neither checks ordinary literal font sizes, padding or gaps across these packages.

The existing [Design & States issue](https://github.com/kontourai/station/issues/4693) is a natural home for side-by-side rendered examples. The [font family and radius decision](https://github.com/kontourai/station/issues/4690) already has an owner. Both can proceed independently of consolidating Settings rows and Connect buttons.
