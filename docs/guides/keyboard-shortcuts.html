Keyboard shortcuts

Open Settings → Keyboard shortcuts to search Station commands by their plain-language names.

  • Select a shortcut, then press the new key combination.
  • If another command already uses it, Station explains the conflict before saving. Choose Replace to clear the old command and move the shortcut, or Cancel to leave both unchanged.
  • Clear removes a shortcut. Restore default returns the command to its shipped binding.
  • Each row explains when the command is available. The internal condition is visible only under Advanced.
  • Browser-reserved combinations carry a warning. They may work more reliably in the desktop app because a browser can intercept them first.

Shortcut changes are stored on this device in the versioned station.device-settings record. They are included in Settings export/import and do not change another device. On phones the list is read-only.
