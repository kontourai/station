The next improvements should reduce concepts, not just controls.

  • Terminal is its own epic. Prove input/paste/keyboard, fit and scroll, process identity, close-versus-terminate, reconnect, Windows PTY and deliberate mobile behavior. A successful pwd is insufficient.
  • Pairing should feel like connecting a device, not administering credentials. Browser launcher sessions can use Station but cannot create invitations. The corrected refusal gives the real operator remedy; a beginner still needs a better trusted handoff and a direct Pair phone entry.
  • Keep the direct mobile project action until we revise its contract. Moving it into Chat actions was proposed, then restored because the repository expressly requires direct Project and conversation switching. A better label and clearer future-chat semantics remain design work.
  • One conversation identity is enough. Mobile Coding still repeats the title in its breadcrumb and chat header. The next design pass should consolidate these while preserving drill-in Back and Chats navigation.
  • Install needs fresh-machine proof. Keep double-click desktop primary where signing supports it. Qualify Windows/Linux, PATH recovery, updates/rollback and first-time AI sign-in. The repaired shell installer is local source until published.
  • Restart recovery still needs work. During the final rebuild, Safari remained on history transport failures and a Claude setup reminder while the server readiness endpoint returned ready. Desktop later resynced automatically; Safari recovered only after relaunching its process. The underlying cause is not established; retain the actual failure capture and verify recovery under load before claiming a smooth restart.
  • Same-host instances need isolated browser credential identity. The earlier two-port cookie collision remains open. Preserve Secure/HttpOnly/SameSite, revocation and migration when addressing it.
  • Repeat with a person unfamiliar with coding. Observe where they hesitate, what they think a Station/Agent/Project means, and whether they can recover without a terminal. Don’t infer simplicity from a developer finishing the flow.
