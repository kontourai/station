# Independent project inspection example

This original package uses the public Agent Plugins and experience contracts.
It needs no core allowlist or Station internals. Its inspection entry reads an
onboarding document and project configuration, produces a cited report, and
refuses missing context or unsupported execution. It complements the interview
and transformation patterns in the [curated collection](../matt-pocock-engineering/README.md).

On Node 24 with a CLI containing this authoring change, run `station plugin
build` in this directory. Inspect and review it using the
[author learning path](../../docs/guides/authoring-skill-experiences.md), then
preview/install through normal Plugin consent in an isolated Station home.
Choose an agent with project and file read capability. A locally built example
is not an independently published consumer or a runtime qualification receipt.
Copy this package outside the repository and use exact released public tooling
to qualify that path after publication. Rich interfaces need their separately
supported extension contract; this example declares only ordinary controls.
